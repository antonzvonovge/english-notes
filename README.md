# English notes

Public Quartz site for the **English** project from the private MarkSpace vault [`antonzvonovge/my-markspace`](https://github.com/antonzvonovge/my-markspace).

- Site: https://antonzvonovge.github.io/english-notes/
- The vault is never modified; CI sparse-checkouts only `English/` on a schedule (every 30 minutes) or via **Actions → Deploy English notes → Run workflow**.

## Access to the private vault

Repository secret `VAULT_SSH_KEY` holds a private key whose public half is a **read-only deploy key** on `my-markspace` (title: `english-notes CI (read-only)`). No files are added to the vault.
